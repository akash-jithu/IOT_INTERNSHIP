# Task 1 — Day 1

## Objective

Set up the development environment for the IoT edge node and verify that the microcontroller board is working correctly.

## Work Completed

* Installed and configured Arduino IDE.
* Installed the required ESP32/ESP8266 board package.
* Set up the required USB-to-serial driver.
* Connected the development board to the computer.
* Selected the correct board and COM/serial port.
* Uploaded a basic Blink program.
* Tested serial communication using the Serial Monitor.
* Verified that the board responds correctly to the uploaded firmware.

## Firmware

The `firmware/` folder contains the Arduino code used for the Day 1 board test.

### Test Performed

The Blink program was used to verify:

1. USB connection
2. Board detection
3. Firmware upload
4. Microcontroller execution
5. Basic GPIO operation

The development environment was successfully configured, and the microcontroller board was successfully programmed and tested using Arduino IDE.
